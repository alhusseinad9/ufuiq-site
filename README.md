# موقع أُفُق (UFUQ)

صفحة واحدة ثابتة (HTML/CSS فقط) لموقع الشركة على ufuqtech.ly، مستضافة على GitHub Pages.

- `index.html`: الصفحة كاملة (الخط IBM Plex Sans Arabic من Google Fonts).
- `assets/`: الشعار والأيقونات.

قبل الإطلاق الرسمي: احذف سطر `<meta name="robots" content="noindex, nofollow">` من `index.html`.
لتعديل التواصل: بدّل «قريباً» بالبريد أو الرقم الحقيقي فقط.
